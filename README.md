# 推し酒 - 日本酒コレクション管理アプリ

**見つける、育てる、語り合う。**

推し酒は、日本酒愛好家のための包括的なコレクション管理とコミュニティアプリケーションです。静的HTML/CSS/JavaScriptで構築されたモバイルファーストのWebアプリケーションで、日本酒の収集、キャラクター育成、味覚診断、コミュニティ機能を提供します。

![推し酒アプリ](https://via.placeholder.com/800x400/DC2626/ffffff?text=%E6%8E%A8%E3%81%97%E9%85%92+App)

## ✨ 最新アップデート

### 🎨 AI推し酒キャラクター生成機能 実装！

日本酒のラベルをカメラで撮影するだけで、**最高峰AI（Ideogram V3 + Gemini Flash）**が美しい2次元アニメキャラクターを自動生成します！

**主な特徴：**
- 🎭 ラベルデザインを完全反映
- 🌸 日本の美を表現した高品質イラスト
- 💎 自動レアリティ判定
- 🏷️ AI自動命名機能
- 🍶 味覚プロファイル推定

## 📱 使用方法

### 基本操作
1. **スプラッシュスクリーン**: アプリ起動時の美しいローディング画面
2. **タブナビゲーション**: 下部の7つのタブで機能切り替え
3. **データ永続化**: 設定や記録は自動的にローカルストレージに保存

### AI推し酒キャラ生成 ⭐
1. カメラタブを開く
2. 「再撮影」ボタンでカメラ開始、または「ファイル」ボタンで画像選択
3. 日本酒ラベルを撮影・選択
4. **AI自動分析・生成**（30-60秒）
   - Gemini がラベルを分析
   - Ideogram V3 が美しいアニメキャラを生成
5. 生成されたキャラクターを確認
6. 「コレクションに追加」で図鑑に保存

### テイスティング記録
1. テイスティングタブを開く
2. 銘柄、性別、年代を選択
3. 5軸の味覚スライダーで評価
4. 「記録する」ボタンで保存
5. レーダーチャートで結果確認

### AI診断・推薦
1. AI診断タブを開く
2. 味覚プロファイルを確認
3. スライダーで手動調整可能
4. AI推薦でマッチする日本酒を表示

## 📊 データモデル

### 日本酒データ構造
```javascript
{
  id: string,
  brand_name: string,           // 銘柄名
  brewery_name: string,         // 酒蔵名
  region: string,               // 地域
  sake_type: string,            // 種類（純米大吟醸など）

  character_level: number,      // レベル
  character_exp: number,        // 経験値
  character_rarity: 'common'|'rare'|'epic'|'legendary',
  character_image: string,      // キャラクター画像URL
  collected_date: string,       // 収集日時
  taste_profile: {             // 味覚プロファイル
    sweetness: number,         // 甘み (1-5)
    acidity: number,           // 酸味 (1-5)  
    umami: number,             // 旨み (1-5)
    bitterness: number,        // 苦味 (1-5)
    aroma: number              // 香り (1-5)
  },
  user_rating: number,         // ユーザー評価 (1-5)
  user_notes: string,          // ユーザーメモ
  favorite: boolean            // お気に入り
}
```

## 🤖 AI生成システムの詳細

### 使用AI技術

#### 1. **Ideogram V3** - キャラクター画像生成
- 顔の一貫性に優れた最高峰モデル
- 高解像度の美しいアニメイラスト生成
- キャラクターデザインに特化

#### 2. **Gemini Flash Vision** - ラベル分析
- 高速な画像理解AI
- ラベルデザインの要素抽出
- 色彩、モチーフ、雰囲気の分析

### 生成プロセス

1. **ラベル撮影/アップロード** → 画像取得
2. **Gemini分析** → デザイン要素抽出（色、モチーフ、雰囲気など）
3. **キャラクター名生成** → AIによる命名
4. **Ideogram生成** → 2次元アニメキャラクター画像生成（30-60秒）
5. **レアリティ決定** → ランダムで決定（Common/Rare/Epic/Legendary）
6. **味覚プロファイル推定** → 雰囲気から味覚を推定
7. **図鑑登録** → コレクションに追加

### 生成されるキャラクターの特徴

- ラベルの色彩を反映した配色
- デザインモチーフを衣装に反映
- 季節感のある装飾
- 日本的な美しさを表現
- 高品質なアニメイラスト

## 🐛 既知の問題・制限事項

### 1. AI生成機能
- 生成には30-60秒かかります
- インターネット接続が必要
- API制限により連続生成に制限がある場合があります
- 複雑なデザインの場合、分析に時間がかかることがあります

**エラーが発生した場合:**
1. **ブラウザコンソール（F12）でエラー確認**
2. **ネットワーク接続を確認**
3. **画像が明瞭か確認**（ぼやけていない、反射なし）
4. **時間をおいて再試行**
5. **別のブラウザで試す**（Chrome推奨）

### 2. カメラ機能
- HTTPS環境でのみ動作
- 一部のブラウザで制限あり

### 3. データストレージ
- ローカルストレージのみ（容量制限）
- バックアップ機能なし

### 4. パフォーマンス
- 大量データ時の表示速度
- アニメーション重複時のメモリ使用量

## 💡 使用のヒント

### より良いAI生成結果を得るために

1. **ラベル撮影のコツ**
   - 明るい場所で撮影
   - ラベル全体が映るように
   - ピントをしっかり合わせる
   - 反射や影を避ける

2. **最適なラベル**
   - デザイン要素が豊富なラベル
   - 色彩が鮮やかなもの
   - 伝統的な和柄や書道
   - 季節感のあるデザイン

3. **生成時間**
   - 初回生成: 30-60秒
   - 複雑なデザイン: やや時間がかかる場合あり
   - 通信環境により変動
